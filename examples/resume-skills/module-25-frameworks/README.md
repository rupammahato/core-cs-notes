# M25: LangChain, LangGraph and LlamaIndex

Actual framework runtimes, explicit fake/scripted responses and handwritten feature vectors. No learned model, API key, provider call, hosted tracing or remote vector store.

Run from the repository root in PowerShell:

```powershell
python -m venv examples/resume-skills/module-25-frameworks/.venv
& examples/resume-skills/module-25-frameworks/.venv/Scripts/python.exe -m pip install -r examples/resume-skills/module-25-frameworks/requirements-lock.txt
& examples/resume-skills/module-25-frameworks/.venv/Scripts/python.exe -X utf8 examples/resume-skills/module-25-frameworks/verify.py
```

The recorded runtime is Python 3.12.10, LangChain 1.4.6/core 1.6.10, LangGraph 1.2.15/checkpoint 4.3.0/SQLite saver 3.1.2, LlamaIndex core 0.14.25 and Pydantic 2.14.1. All resolved versions are locked. `pip check` checks dependency consistency, not vulnerabilities.

`verify.py` runs 89 checks: LangChain composition/parsing/batch/async/stream (14), retry/loop budgets (4), actual agent/tool behavior (10), graph state/reducers (7), process-restart persistence (11), approval/authorization (8), effect replay recovery (7), source freshness (5), LlamaIndex (18), offline/process checks (3) and cleanup (2).

The process suite launches 21 workers. Each worker action uses a new OS process and file-backed SqliteSaver. The canonical application database remains separate from the checkpoint database. The suite pauses/resumes review, rejects wrong tenant/user/hash/types, rechecks revocation and source changes, and injects a failure after a canonical write but before node completion. Recovery retries the node without duplicating the result row. This tests a narrow local transaction invariant, not remote exactly-once effects, concurrent-resume leases, power failure or production durability.

LangChain uses FakeListChatModel and an explicitly scripted BaseChatModel implementation. Its bind_tools returns itself and never calls a provider. The lexical helper enforces trusted principal scope; it is not semantic retrieval. LlamaIndex uses actual SentenceSplitter/IngestionPipeline/VectorStoreIndex, a three-word-count encoder and explicit MockLLM. Word counting is deliberately distinct from BPE token budgeting. Metadata filters, persistence/reload and source deletion are tested on the local store.

`domain.py`, `langchain_demo.py`, `repository.py`, `graph_demo.py`, `graph_worker.py` and `llama_demo.py` are embedded verbatim in the notes. `offline.py` installs an external-socket audit guard. Parent/worker tracing is disabled and the observed paths made zero external socket attempts. Principals and approval values are synthetic trusted test inputs; the CLI is not an authenticated web service. Production API identity must come from verified credentials.

Temporary application/checkpoint/index files are removed in `finally`; all workers exit and handles close. No persistent listener starts. The existing PostgreSQL service is untouched, Docker stays stopped and port 3000 stays stopped. The site validator starts and closes only its own ephemeral preview.

Evidence: `verification-results.json`, `cleanup-results.json`, `dependency-check.txt`, `content-validation.json`, `site-validation.json` and `validation-summary.json`. The last reports are generated by `validate_site.py` after notes integration. Recorded callbacks are local and do not upload prompts or passages.
